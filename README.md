# إفراز الأراضي

تطبيق أندرويد لتقسيم قطعة أرض بين الشركاء من ملف DXF:

- **حدود القطعة:** بوليلاين مغلق في ملف DXF.
- **الاقتطاع المسبق بالأحمر (رقم 1):** كل طريق معتمد أو فضلات طرق أو قسيمة تقترحها البلدية، يُرسم بوليلاين مغلقاً أحمر ويُخصم أولاً ضمن نسبة الاقتطاع.
- **الطرق الخارجية بالأزرق (رقم 5):** خط فوق الضلع الذي عليه طريق قائم، ومنه تنطلق الطرق الداخلية المقترحة.
- **الحصص:** من ملف PDF الذي يصدره تطبيق «حاسب الكواشين»، أو إدخال يدوي.
- **داخل البلدية:** اقتطاع 30% (قابل للتعديل)، حد أدنى للمساحة والعرض، ودمج الحصص الصغيرة في قسائم مشتركة.
- **خارج البلدية:** الاقتطاع = مساحة الطرق فقط.
- **الطرق المقترحة:** منحنيات عند التقاطع، ودوار عند نهاية الطريق المغلق، وخيار إنهاء الطريق بعد قسيمة محددة.
- **التصدير:** DXF للأوتوكاد، تقرير PDF، جدول CSV.
- يعمل دون اتصال بالإنترنت.

## تحميل التطبيق

افتح صفحة **Releases** في هذا المستودع وحمّل `ifraz-app.apk` ثم ثبّته على الهاتف.
(قد يطلب الأندرويد السماح بالتثبيت من مصدر غير معروف.)

## تعديل التطبيق

الملف الأساسي هو `www/index.html`. عند رفع أي تعديل إلى فرع `main` يبني GitHub Actions ملف APK جديداً
وينشره في Releases خلال بضع دقائق.

## الأيقونة

مخطط إفراز أصلي مرسوم للتطبيق، وملفاتها في `resources/android`، ويطبّقها `scripts/apply-icons.sh` عند البناء.
